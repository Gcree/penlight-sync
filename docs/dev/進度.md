## 終端機啟動問題修正

使用者回報連線後手燈與程式同時結束。實際從啟動檔重現，確認是終端機沒有螢幕錄製權限。已新增連線前權限請求、首次授權後可用性複查、中文錯誤、保留錯誤視窗與本機記錄；使用者已允許並重新開啟終端機。

修正後正式終端機程序已連續運作超過兩分鐘，重跑五色全螢幕色塊均取得裝置 ACK，返回原畫面後持續連動。

## 視窗版（Mac GUI 與 Windows）

2026-10-23 晚間新增：

- Mac：`dist/PenlightSync.app`（SwiftUI，universal），可掃描並選擇手燈、開始／停止、即時顯示螢幕主色與手燈已確認的顏色、執行記錄；記住上次選的手燈，不再寫死裝置 ID。沿用已驗證的取色、編碼與 8 秒逾時保護。
- Windows：`dist/windows/PenlightSync.exe`（.NET 8 WinForms，單一執行檔，內含執行環境），功能與畫面同 Mac 版；在 Mac 上交叉編譯。
- Windows 的加密指令與主色演算法為 Swift 版的 C# 移植，以相同實測向量（紅／綠／藍／黑／白）驗證一致。

Mac 視窗版修正版已實機重測掃描、五色連動與停止，使用者確認手燈實體依序變色（見 `驗證紀錄.md`）。注意：每次重新編譯 App 後，需重新允許藍牙，並在「螢幕與系統錄音」手動以「+」加入 App。

尚未驗證：Windows 版尚未在實體 Windows 電腦與手燈上執行（藍牙、螢幕擷取、高 DPI 版面都只經過編譯）。自動重新連線仍未實作。

## v1.3.0：框選取色範圍、斷線自動重連、依 BPM 調整快慢（Mac、Windows）

- 取色範圍：可拖曳框選影片所在區域（Esc 取消），或改回整個主螢幕；設定會被記住，連動中可改。
- 斷線自動重連：連動中斷線、寫入失敗或寫入逾時時，保留燈光狀態並自動重新連線最多 30 秒，失敗才停止。
- 依 BPM 調整：節拍偵測同時估算 BPM（顯示在畫面上），以 120 BPM 為基準把漸變時間縮放到 0.6～1.4 倍，閃光長度約三分之一拍。
- Swift 與 C# 新增 BPM 估算（120／150／90 BPM）與快慢歌漸變比較測試，全部通過；Windows `-warnaserror` 編譯通過。使用者選擇先發布，尚未用手燈實機驗證（見 `驗證紀錄.md`）。

## v1.7.0：網站模式（與 Ado 應援預習網站連動；Mac、Windows）

- 網站模式：新增「取色來源」（螢幕 / 網站（Ado 應援預習））。在網站模式下，App 在本機啟動 WebSocket 伺服器（監聽 `127.0.0.1:51730`），接收來自 Ado 應援預習網站的歌曲播放進度、應援色與拍點資料，直接驅動手燈變色與閃動，不需要螢幕錄製或麥克風權限。
- 核心求值器（`SiteLight` / `SiteLightEvaluator`）：純邏輯模組，以 10 項單元測試涵蓋播放秒數換算、128 BPM 基準節奏、小節換色、4 秒換色、聽 cue 變暗、副歌高潮 8 拍閃動、序號丟棄與 5 秒未收到狀態之待機處理。Swift 與 C# 實作邏輯與測試完全對齊。
- 通訊與安全（`SiteLink` / `SiteLinkWin`）：嚴格限定本機 loopback `127.0.0.1` 監聽，檢查 Origin 白名單（`https://gcree.github.io`、`localhost`、`127.0.0.1`），限制單一連線，支援連接埠佔用偵測與燈光狀態同步。
- 介面：即時卡片在網站模式顯示「網站顏色」與歌曲名稱／播放狀態（例如 `〈踊〉播放中`）；取色範圍分頁提示網站模式無需框選；螢幕模式維持預設且行為與先前完全一致。
- 現場感與音樂動態微隨機（依使用者回饋增強）：
  1. 換色頻率全面提速（1～2 拍換一次）：一般段落由 4 拍提速為每 2 拍換色；嗨歌互動動作（`jump`、`call`、`clap`）與快歌加速為每 1 拍換一次色。
  2. 連續鼓聲極速切換（Rapid Drum Roll）：副歌高潮（`climax`）、快節奏跳躍段落或小節末鼓點過門時，換色加速為每 0.5 拍（半拍）極速交替，並以半拍連擊脈衝驅動手燈。
  3. 網站模式淡入時間優化：將網站模式下的漸變淡入時間調整為乾脆俐落的 0.20 秒（螢幕模式維持 0.60 秒不變），讓 1～2 拍與連續鼓聲的快速換色刀刀見肉、完全不拖泥帶水。
  4. 舞台盲閃白光爆破（Concert Stage Blinder Pop）：快歌（BPM >= 115）在大鼓第 1 拍重拍上有機爆閃 70ms 高亮白光，隨後綻放為歌曲原色，重現演唱會現場盲閃大燈效果。
  5. 鼓點力度有機微隨機：擺脫呆板的數位時鐘感，第 1 拍重拍、第 3 拍次重音與第 2、4 拍弱音具備自然動態擾動，快歌第 4 拍偶爾加入鼓點過門音。
  6. 螢幕取色般的色彩微晃動與單色歌跳色：每拍微幅擾動色彩明暗，單色歌曲（如逆光）在重音上偶爾閃現舞台琥珀金等互補點綴色，消除單調感。
  7. 重拍前下潛蓄力（Pre-beat Dip）：大鼓第 1 拍抵達前約 80ms（第 4 拍末 `beatFraction >= 0.82`）先將亮度迅速壓暗至 28%，大鼓落地瞬間暴衝滿亮，視覺對比躍升 4～5 倍。
  8. 100% 舞台大盲閃白光（Stage Blinder Pop）：快歌重拍 100% 觸發 80ms、高達 86% 白色核心的舞台高光盲閃，隨後迅速綻放回原色。
  9. 拍間動態深度拉大（Dynamic Contrast Expansion）：網站模式 `beatDepth` 拉大到 0.65（拍間底暗降至 35%，原為 55%），重拍與弱拍層次更分明；螢幕模式保持 0.45 預設值不受任何影響。
  10. 間奏與常規歌詞誤判修復（`ado-guide` 網站端）：修正 `currentCue(t)` 將無特定動作行誤傳為 `"listen"` 的問題，解決〈Monstruo〉1:55 等無歌詞強節奏間奏被靜音的根源。
  11. 雙向相互連動效果與 GUI 連結：PenlightSync GUI 加入直達網站與歌曲的連結按鈕（即時卡片與色彩頁）；網站端在手燈連動時亮起綠色呼吸光暈並在控制列顯示「手燈連動中」動態徽章，並提供雙向握手通知與未連線引導 Toast。
  12. 自動更新偵測修復：修復 GitHub REST API 因缺少 `User-Agent` 標頭而回應 403 的問題，並於 Mac 與 Windows 同步加入透過 HEAD releases/latest 重定向位址讀取版本的備援方案，徹底避免 GitHub API 額度限制。
- 測試與相容：自動測試驗證瀏覽器開關狀態連線、速率限制（<= 5 msgs/sec）、切換歌曲停止訊號。**Windows 版已在 Mac 上以 .NET 8 交叉編譯通過並通過純邏輯自測，尚未在實體 Windows 電腦上執行**。
